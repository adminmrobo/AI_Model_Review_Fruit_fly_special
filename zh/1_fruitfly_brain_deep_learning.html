果蝇如何闻、如何看、如何察觉

即使在芝麻粒大小的果蝇脑袋里，信号也沿着固定的路线前进。触角和复眼把世界变成电信号，神经把这些信号整理后传送出去，大脑则察觉到“这是食物”“有危险”。而这些判断的规则并不是谁事先规定好的，而是通过经验学来的。沿着这条路走下去，人工神经网络如何从超简单模型成长为多层深度学习，就会自然而然地呈现在眼前。

为什么偏偏用果蝇来学神经网络

人脑太大，计算机里的神经网络又太抽象。果蝇的大小恰好介于两者之间。从感觉器官到行为的整条通路一目了然，而且这条通路上的每一个神经元都可以真正地打开、关闭来做实验。

理由 1完整的接线图已经公开

2024年，包含果蝇全脑神经元及其连接的接线图（连接组）绘制完成。用神经网络来比喻，就相当于可以完整地看到模型的结构和连接。

理由 2从输入到输出又短又清晰

闻到气味就靠近，看到逼近的阴影就起飞。感觉 → 神经 → 大脑 → 行为的路径很短，很适合一步一步地追踪。

理由 3可以只开关想要的神经元

利用遗传工具，可以让特定神经元停止工作。这就像在神经网络里删掉一个单元，看看性能会如何变化的实验。

为什么偏偏是电——五个理由

  1. 通用语言：只有把光、气味、声音、味道都转换成同一种形式，大脑才能在一个地方把它们混合、比较。这和深度学习把照片、文字、声音都变成数字列表的道理相同。
  2. 速度快：如果靠气味分子在体内漂浮扩散的速度，根本躲不开苍蝇拍。靠离子流动传递的电信号，转眼间就能从身体末端到达大脑。
  3. 传得再远也不会变弱：脉冲沿着轴突前进时会不断重新生成，所以即使走很长的路，幅度也不会减小。
  4. 强度用“几次”来表示：单个脉冲的幅度总是一样的，刺激越强，发放得越频繁。不是用幅度而是用次数来传递强度，所以抗噪声能力强。这个发放频率就相当于人工神经元的“输出数值”。
  5. 可以在突触处调节强度：在神经元与神经元之间的缝隙里，电会转变成化学物质（神经递质）跨越过去。传递得多少、传递得有多好，就是权重；而学习，就是改变这种传递效率。

也有例外。像复眼的光感受器这样只在短距离内传送信号的神经元，不发放脉冲，而是让电压连续地升降来传递信息。选择“光”来看看其中的区别吧。

是给定规则，还是学习规则

让计算机做事有两种方法：由人一条一条地写好规则（基于规则），或者只给出例子和结果，让它自己找出规则（基于学习）。深度学习属于第二种，而果蝇的大脑里两种方法都有。

基于规则（Rule base）

有人事先写好规则

如果 果香 > 0.5 → 靠近
如果 二氧化碳 > 0.3 → 躲开
其他情况 → 原地不动

规则一目了然，容易理解。但必须事先知道世界上的所有情况，环境一变，写规则的一方就得亲自修改。遇到规则里没有的情况，就束手无策了。

在果蝇中：侧角的先天反应。写下规则的是进化，一只果蝇一辈子都改不了这些规则。

基于学习（Learning）

看到结果后自己修改规则

1. 用当前的值进行预测并采取行动
2. 观察实际结果（食物 +1，电击 −1）
3. 值 ← 值 + η × (结果 − 预测)

不直接写规则，而是按照“预测错了多少”来修改权重。反复这样做，规则就会自然而然地出现在权重里。即使环境变了，也能重新学习。

在果蝇中：蘑菇体。当惩罚或奖励到来时，多巴胺神经元发出信号，改变 Kenyon 细胞 → 输出神经元的连接。这个信号是否像“结果 − 预测”那样计算预测误差，目前仍在研究中；这里为了便于理解，简化成了预测误差规则。

天生倾向相同的两只果蝇，世界变了会怎样？

两只果蝇一开始都喜欢果香 A。但在这个房间里，A 那边有电击，B 那边有糖。左边的果蝇只按规则行动，右边的果蝇则根据结果来学习。点击“改变环境”，换一换危险的一侧吧。

右边那只果蝇的“规则”并没有以文字的形式写在任何地方，它的全部只是两个“靠近值”，也就是两个权重。深度学习模型也一样：几百万、几十亿个权重本身就是规则，所以性能虽好，却很难用人类的语言说出“为什么这样判断”。基于规则容易解释，基于学习容易适应。果蝇把两者结合起来：遇到第一次见的情况时靠先天规则撑住，积累经验后再用学到的规则加以修正。

模型阶梯——依次登上四级台阶

每往上爬一级，就多一种能在果蝇身上看到的能力。在每一级亲手操作模型，遇到这个模型解决不了的问题后，再进入下一级。

1超简单

一个输入，一个连接——闻到二氧化碳就躲开

模型：y = w × x果蝇：回避二氧化碳

在果蝇中

果蝇的触角上有专门只感知二氧化碳的感觉神经元。这个信号汇聚到触角叶的一个嗅小球，果蝇不用学习就会躲开二氧化碳。这里把这条通路大大简化为“一个传感器 → 一个连接 → 行为”来看。

在神经网络中

这是最小的模型：输入 x 乘以权重 w，结果超过阈值 θ 就输出 1，否则输出 0。权重表示“对这个输入听得有多认真”，阈值表示“有多容易作出反应”。

二氧化碳浓度 x
连接强度 w
阈值 θ

给初学者的讲解

在这个模型里，“学习”就是把 w 和 θ 调到合适的值。果蝇生来就带着经过进化调好的这些值。w 调大，淡淡的二氧化碳也会让它逃走；w 调小，浓度很高时才会逃。

局限也很明显：这个模型只看一个输入。果蝇实际面对的问题，比如“果香和醋味一起飘来，能不能吃？”这种需要同时权衡多个信号的问题，它就解决不了。所以要增加输入。

2简单

权衡多个输入的单个神经元——感知机

模型：y = σ(w₁x₁ + w₂x₂ + b)果蝇：判断食物气味

在果蝇中

熟透的水果会同时散发果香（酯类）和醋味（乙酸）。假设一个神经元接收两个嗅小球的信号，来判断“这是不是食物的气味”。它给两个信号不同的分量，相加后再作判断。

在神经网络中

把多个输入各自乘以权重后相加，再加上偏置 b，然后用 Sigmoid 函数 σ 转换为 0~1 之间的概率。这个模型能画出的边界，只是右侧平面上的一条直线。

“学习”实际上做了什么——四个步骤

  1. 预测：用当前的 w₁、w₂、b 计算一种气味的分数。
  2. 误差：测量正确答案（食物 1，不是 0）与预测概率之间的差距。
  3. 分配责任：把误差乘以各个输入的大小，求出每个权重造成了多大的错误。
  4. 修正：把权重朝相反方向挪动一点（挪动学习率 η 那么多）。对所有气味重复这一过程。

选择“困难问题”来训练看看。真实的果蝇会靠近淡淡的醋味，却会躲开太浓的醋味。食物区域变成了两条线之间的带状，而一条直线没法把这条带切出来。无论学多久，准确率都会停在某个水平上。这就是必须进入下一级的原因。

3一般

一个隐藏层——触角叶 → 蘑菇体 → 输出神经元

模型：输入 2 → 隐藏 H → 输出 1果蝇：蘑菇体回路

在果蝇中

触角叶的信号会扩散到蘑菇体的几千个 Kenyon 细胞。每个 Kenyon 细胞挑选几个嗅小球接收信号，对自己独有的“气味组合”作出反应。输出神经元汇总这些反应，决定是靠近还是躲开。学习主要发生在 Kenyon 细胞 → 输出神经元的连接上。

在神经网络中

在输入和输出之间插入一个“隐藏层”。每个隐藏神经元在平面上各画一条线，输出神经元把这些线组合起来，就能做出弯曲的或带状的边界。这就是多层感知机（MLP）。

气味输入→ 隐藏层计算（前向传播）→ 输出·误差→ 反向分配责任（反向传播）→ 修改权重

死记的和理解的——训练数据与验证数据

提前看过考题再复习的学生，就算那次考试拿了 100 分，也证明不了真实水平。模型也一样。所以要把数据分成两份：只用训练数据（实心点）来修改权重，用学习中从未用过的验证数据（空心点）来评分。真正的实力看验证分数。

  1. 欠拟合：训练分数也很低。模型太简单了。第②级的困难问题就属于这种情况。
  2. 刚刚好：训练分数和验证分数都高，而且相近。
  3. 过拟合：训练分数高，验证分数却低。数据太少或混有错误答案时，模型会不去学规则，而是把一个个例子背下来。选择“数据少且有噪声”来确认一下吧。

防止过拟合的常见方法有：增加数据；在验证损失重新开始上升时停止学习（早停）；不要把模型做得比需要的更大。果蝇也会遇到类似的问题：为了不把一次偶然的经历过度泛化，需要经过反复训练才能形成持久的记忆。在实际的深度学习中，除了验证数据，有时还会另外留出一份只在最后使用一次的测试数据。

用大白话讲反向传播

这是一种把输出端产生的误差，按照“是谁的责任”反向分配下去的计算。与输出神经元连接越强的隐藏神经元，以及当时被激活得越强的隐藏神经元，承担的责任就越大。责任确定后，连同输入 → 隐藏的连接也一起修改。

果蝇不做这种反向分配。通向 Kenyon 细胞的连接几乎是随机确定的，而且不会改变；多巴胺只修改最后一段连接（Kenyon 细胞 → 输出神经元）。选择“果蝇方式”试试：隐藏神经元少时效果不好，但把数量增加到 30~60 个，仅凭随机的线也能把带状区域切出来。由此可以推想，果蝇为什么要拥有约2,000个 Kenyon 细胞。

4多层

多层堆叠的视觉通路——看到逼近的阴影就逃跑

模型：像卷积神经网络一样层层堆叠果蝇：复眼 → 视板 → 髓质 → 小叶 → 巨纤维

在果蝇中

苍蝇拍一逼近，果蝇转眼就飞走了。复眼的小眼测量亮度，视板区分变亮与变暗，髓质和小叶板中的 T4·T5 神经元计算运动方向，小叶的 LPLC2 神经元察觉“向四面八方扩散的运动”，也就是正在逼近的物体。这个信号经过巨纤维神经元，变成起跳行为。

在神经网络中

这与卷积神经网络（CNN）的结构相同。每一层都只看一个小区域，并在所有位置重复同样的计算（权重共享）；层次越高，看到的范围越大，特征也越复杂。亮度 → 亮度变化 → 运动方向 → 逼近。每一层都很简单，堆叠起来却能做出困难的判断。

复眼 · 亮度→ 视板 · 变亮/变暗→ 髓质·小叶板 · 运动方向→ 小叶 · 检测逼近→ 巨纤维 · 起跳

这是为了讲解而简化的计算模型。小眼数量从约800个减少到169个，运动方向直接由物体边缘的速度算出。真实的 T4·T5 神经元是通过比较相邻小眼信号的时间差来判断方向的。

为什么要堆叠多层

很难写出一条规则，直接从小眼的亮度值一步判断出“逼近的物体”。因为物体可能是暗的也可能是亮的，可能在右边也可能在左边。于是把问题拆成简单的小块，每一层负责一块。

  1. 第1层（视板）：这个小眼刚才是变暗了，还是变亮了？
  2. 第2层（髓质·小叶板）：和相邻小眼比较，边缘在往哪个方向移动？
  3. 第3层（小叶）：上、下、左、右四个方向上，是否都有向外扩散的运动？
  4. 输出（巨纤维）：如果是，现在就起飞。

“从旁边经过的物体”一侧边缘向外移动，另一侧却向内移动，无法同时满足四个方向。所以即使它又大又快，果蝇也不会起跳。从照片中认出猫的 CNN 也是这样，按线条 → 边角 → 局部 → 整体形状一层层堆叠起来的。

特别篇①页面中的阶梯（超简单 → 多层）讲的是 MLP 和 CNN 那一路。果蝇方式则在旁边给出了另一种答案：“隐藏层即使不学习，只要做得又宽又稀疏，效果也相当不错。”在机器学习中，随机特征、极限学习机（ELM）、储备池计算都是同样的思路。果蝇大脑里也有像 RNN·LSTM 那样处理时间的回路（中央复合体），但本页的模型属于一次性作出判断的那一类。

与 Teachable Machine 的相同点

建立类别 → 收集示例 → 训练 → 对新输入做出判断，流程完全一样。

不同点

Teachable Machine 是在大型图像模型（MobileNet）预先学好的特征之上，只训练一个小分类器（迁移学习）。本例则让两个模型从零开始学习 16×16 的图画。因此它适合简单的形状，不适合照片这类复杂的输入。

类比是理解的第一步，但也可能是误解的种子。果蝇·大脑类比标注了强度：直接 有证据表明确实做着同样的事 · 部分 只有部分性质相似 · 无 尚未发现对应物

概念日常类比果蝇·大脑类比类比出错的地方
感知机给多个人的意见打分并相加，总分超过标准就做决定部分 神经元汇集输入，越过阈值就放电真实神经元的输入会随时间累积又泄漏。感知机里没有时间（参见特别篇 3 的泄漏积分发放）

权重学习把做错的题记进错题本，下次改正直接 多巴胺改变蘑菇体输出连接的强度，把气味和结果配对果蝇的多巴胺信号是否在计算“预测误差”仍在研究中。本篇的学习规则为便于讲解做了简化

练习题（点击展开解析）

Q1. 两个输入（1, 0）、权重（0.8, −0.5）、阈值 0.5 的感知机，输出是多少？

总和 = 1×0.8 + 0×(−0.5) = 0.8。因为 0.8 ≥ 0.5，所以输出 1。

Q2. 感知机为什么解不了“带状”（只有中间是食物）问题？

感知机只能用一条直线（一个平面）来划分。带状区域两侧需要两条边界，一条直线分不开。隐藏层可以造出多条边界再把它们组合起来。

Q3. 训练准确率 96%、验证准确率 59%，说明发生了什么？请给出两种对策。

过拟合：模型背下了训练数据。对策：收集更多数据、减少隐藏神经元、提前停止训练，任选两种。

Q4. 在果蝇方式中，被训练的连接和固定的连接分别是什么？

固定：投射神经元 → Kenyon 细胞（随机稀疏连接）。训练：Kenyon 细胞 → 输出神经元（由多巴胺改变）。

Q5. 在代码 2 中，果蝇方式（训练 4,004 个连接）取得了与 MLP（训练 16,708 个连接）相近的准确率，这说明了什么？

仅凭宽而稀疏的固定表示，简单的图画问题只需训练输出层就足以解决。但由于无法改进表示本身，在困难问题上会有局限。
